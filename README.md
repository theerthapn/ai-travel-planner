# ✈️ AI Travel Planner – Gemini Powered Trip Planner & Itinerary Assistant

## Project Overview

AI Travel Planner is an AI-powered web application built using Streamlit and Google Gemini AI.

It creates personalized travel itineraries based on destination, budget, travel style, travel pace, trip type, interests, and food preference.

The application also includes a Smart Budget Planner, budget visualization, PDF/TXT downloads, and an AI Travel Assistant.

## Features

- ✈️ Personalized AI Travel Itinerary
- 🤖 Google Gemini AI Integration
- 💰 Smart Budget Planner
- 📊 Budget Visualization
- 🔄 Regenerate Travel Plan
- 💬 AI Travel Assistant
- 📥 TXT Download
- 📄 PDF Download
- 🧳 Travel Style Selection
- ⏱️ Travel Pace Selection
- 👥 Trip Type Selection
- 🍴 Food Preference Support
- ❤️ Interest-Based Recommendations
- 🔐 Environment Variable API Key
- ⚠️ Gemini API Error Handling
